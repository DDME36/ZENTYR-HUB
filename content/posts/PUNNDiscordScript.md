# รวมสคริปต์ Discord ไว้ในโปรแกรมเดียว

PUNN Discord Script เป็นโปรแกรมบน Windows ที่ผมพัฒนาขึ้นมาเพื่อทดลองจัดการสคริปต์สำหรับกิจกรรมหรือ Quest บางประเภทของ Discord โดยตัวโปรแกรมจะดึงรายการสคริปต์จาก GitHub ทำให้สามารถอัปเดตส่วนที่รองรับได้โดยไม่ต้องแจกตัวโปรแกรมใหม่ทุกครั้ง

แนวคิดหลักคือแยกตัว Launcher ออกจากชุดสคริปต์ เมื่อมีการแก้ไขรายการหรือปรับปรุงความเข้ากันได้ ผู้ใช้จึงสามารถรับข้อมูลเวอร์ชันใหม่จากแหล่งกลางได้ง่ายกว่าเดิม

> บทความนี้อธิบายภาพรวมของโปรเจกต์เท่านั้น ไม่รับประกันรางวัลหรือผลลัพธ์จาก Discord ผู้ใช้ต้องตรวจสอบเงื่อนไขของกิจกรรมและข้อกำหนดของแพลตฟอร์มด้วยตนเอง

## สิ่งที่โปรแกรมออกแบบมาให้รองรับ

- ดึงรายการสคริปต์และข้อมูลเวอร์ชันจาก GitHub
- รวมเครื่องมือไว้ในหน้าต่างเดียว
- แจ้งว่าสคริปต์ประเภทใดพร้อมใช้งานหรือยังไม่รองรับ
- ลดปัญหาการใช้ไฟล์เวอร์ชันเก่าที่กระจายอยู่หลายที่
- เหมาะสำหรับการทดลองและศึกษาการทำงานของกิจกรรม Discord

กิจกรรมที่เกี่ยวกับการดูวิดีโอหรือกิจกรรมบางรูปแบบอาจมีโครงสร้างที่โปรแกรมตรวจพบได้ แต่ Quest ที่จำเป็นต้องเข้าเกม ทำภารกิจเฉพาะ หรือเข้าร่วมอีเวนต์ภายในเกมจริง ๆ ยังไม่รองรับ และไม่ควรคาดหวังว่าโปรแกรมจะทำแทนได้ทุกประเภท

## ทำไมจึงดึงข้อมูลจาก GitHub?

กิจกรรมของ Discord สามารถเปลี่ยนรูปแบบได้ การเก็บรายการสคริปต์ไว้ใน GitHub ช่วยให้ตรวจสอบประวัติการเปลี่ยนแปลงและอัปเดตข้อมูลได้จากจุดเดียว อย่างไรก็ตาม ผู้ใช้ควรตรวจสอบ repository และการเปลี่ยนแปลงล่าสุดก่อนใช้งานเสมอ ไม่ควรรันโค้ดจากแหล่งที่ไม่ทราบที่มา

Repository ที่เกี่ยวข้อง: [DDME36/DC-Quest-Script](https://github.com/DDME36/DC-Quest-Script)

## ข้อจำกัดและความปลอดภัย

- โปรแกรมไม่ควรขอรหัสผ่าน Discord หรือ Token บัญชี
- ไม่ควรปิดระบบป้องกันไวรัสเพียงเพื่อให้โปรแกรมทำงาน
- สคริปต์จากอินเทอร์เน็ตอาจเปลี่ยนแปลงได้ ควรตรวจสอบแหล่งที่มาทุกครั้ง
- Discord สามารถเปลี่ยนระบบ Quest ได้โดยไม่แจ้งล่วงหน้า
- การได้รับรางวัลขึ้นอยู่กับเงื่อนไขของแต่ละกิจกรรมและการตรวจสอบของ Discord

การใช้งานควรอยู่ในบัญชีและสภาพแวดล้อมที่ผู้ใช้มีสิทธิ์ทดสอบ หลีกเลี่ยงการใช้เพื่อหลบข้อจำกัด สร้างข้อมูลเท็จ หรือแสวงหารางวัลโดยขัดต่อกติกาของแพลตฟอร์ม
