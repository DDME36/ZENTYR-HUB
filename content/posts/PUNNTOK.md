# PUNNTOK คืออะไร?

PUNNTOK เป็นโปรแกรมที่ผมทำขึ้นมาเพื่อทดลองนำประสบการณ์ใช้งานแบบเว็บมารวมกับโปรแกรมบนคอมพิวเตอร์ โดยเน้นการควบคุมการกดหัวใจระหว่างรับชม TikTok LIVE จากหน้าจอเดียว ไม่ต้องสลับหน้าต่างไปมาบ่อย ๆ และสามารถใช้งานในลักษณะ **PWA (Progressive Web App)** ได้

จุดประสงค์หลักของโปรเจกต์นี้คือการทดลองเรื่อง UI, การทำงานแบบต่อเนื่อง และการนำเว็บแอปมาติดตั้งให้มีหน้าตาใกล้เคียงโปรแกรมจริงบน Windows

> PUNNTOK เป็นโปรเจกต์ทดลองส่วนบุคคล ผู้ใช้ควรใช้งานอย่างพอดี เคารพกติกาและข้อจำกัดของ TikTok และไม่ใช้เพื่อสร้างสแปม รบกวนผู้อื่น หรือบิดเบือนยอดการมีส่วนร่วม

## จุดเด่นของ PUNNTOK

- ใช้งานบนคอมพิวเตอร์ได้ ไม่ต้องกดผ่านหน้าจอโทรศัพท์ตลอดเวลา
- รองรับการใช้งานแบบเว็บและติดตั้งเป็น PWA
- อินเทอร์เฟซออกแบบให้เปิดใช้งานและควบคุมได้ง่าย
- เหมาะสำหรับทดลองใช้งานกับ LIVE ของตัวเองหรือสภาพแวดล้อมที่ได้รับอนุญาต
- มีเวอร์ชัน Portable สำหรับ Windows ไม่ต้องผ่านขั้นตอนติดตั้งที่ซับซ้อน

## PWA คืออะไร และเหมาะกับโปรแกรมนี้อย่างไร?

PWA คือเว็บไซต์ที่สามารถติดตั้งลงบนอุปกรณ์และเปิดใช้งานในหน้าต่างแยกได้ คล้ายกับแอปทั่วไป ข้อดีคือเปิดได้รวดเร็ว มีไอคอนบน Desktop หรือ Start Menu และยังคงใช้เทคโนโลยีเว็บเป็นพื้นฐาน

สำหรับ PUNNTOK รูปแบบนี้ช่วยให้ตัวโปรแกรมดูสะอาด ไม่ต้องเปิดแท็บเบราว์เซอร์จำนวนมาก และสามารถจัดวางคู่กับหน้าต่าง TikTok LIVE ได้สะดวกกว่าเดิม

## เหมาะกับใคร?

โปรแกรมนี้เหมาะกับคนที่ต้องการทดลองเครื่องมือบนคอมพิวเตอร์ ผู้พัฒนาเว็บที่สนใจการทำ PWA หรือผู้ที่อยากดูแนวทางการนำเว็บแอปมาทำเป็นโปรแกรมแบบ Portable

ไม่ควรใช้โปรแกรมแบบเปิดทิ้งไว้โดยไม่ตรวจสอบ และไม่ควรพยายามฝืนข้อจำกัดของแพลตฟอร์ม เพราะ TikTok สามารถเปลี่ยนแปลงหน้าเว็บ ระบบตรวจจับ หรือเงื่อนไขการใช้งานได้ตลอดเวลา

## สรุป

PUNNTOK เป็นอีกหนึ่งโปรเจกต์ทดลองที่แสดงให้เห็นว่าเว็บแอปสามารถทำงานใกล้เคียงโปรแกรมบน Desktop ได้ จุดเด่นไม่ได้มีเพียงการทำงานกับ TikTok LIVE แต่ยังเป็นพื้นที่ทดลองเรื่อง PWA, UX และการออกแบบเครื่องมือที่ใช้งานได้จากหน้าต่างเดียว
