# แสดงสถานะเกมบน Discord แบบง่าย ๆ

เวลาเปิดเกม Discord มักจะแสดงสถานะว่าเรากำลังเล่นเกมอะไรอยู่ใต้ชื่อผู้ใช้โดยอัตโนมัติ แต่บางครั้งเราอาจต้องการทดลองหน้าตาของสถานะ ทดสอบโปรไฟล์ หรือเปิดสถานะเพื่อความสนุกโดยไม่ต้องติดตั้งและเปิดเกมจริง

**PUNN Activity Studio** คือโปรแกรมบน Windows ที่ผมทำขึ้นมาเพื่อจำลองสถานะลักษณะดังกล่าว ผู้ใช้สามารถเลือกเกมจากรายการภายในโปรแกรม แล้วให้ Discord แสดงเหมือนกำลังเล่นเกมนั้นอยู่

<!-- รูปที่ต้องเพิ่ม: ภาพปก PUNN Activity Studio -->

## โปรแกรมนี้ทำอะไรได้บ้าง?

- เลือกชื่อเกมจากรายการที่เตรียมไว้
- เปิดหรือหยุดการแสดงสถานะได้จากโปรแกรม
- ใช้งานบนคอมพิวเตอร์ร่วมกับ Discord Desktop
- ไม่จำเป็นต้องดาวน์โหลดหรือติดตั้งเกมที่เลือก
- เหมาะสำหรับทดลองโปรไฟล์และศึกษาการทำงานของ Activity Status

สถานะที่ปรากฏเป็นเพียงข้อมูลสำหรับแสดงผลบน Discord เท่านั้น โปรแกรมไม่ได้เปิดตัวเกมจริง ไม่ได้เพิ่มชั่วโมงเล่น ไม่มี achievement และไม่สามารถปลดล็อกไอเทมหรือกิจกรรมภายในเกมได้

## ใช้ทำอะไรได้บ้าง?

ตัวอย่างการใช้งานที่เหมาะสมคือการทดลองว่าชื่อเกมแต่ละแบบแสดงบนโปรไฟล์อย่างไร จัดธีมโปรไฟล์ให้เข้ากับกลุ่มเพื่อน หรือศึกษาการเชื่อมต่อระหว่างโปรแกรม Desktop กับระบบ Activity ของ Discord

ควรบอกเพื่อนตามตรงหากสถานะดังกล่าวเป็นเพียงการจำลอง และไม่ควรใช้เพื่อแอบอ้างการแข่งขัน เวลาเล่น หรือความสำเร็จที่ไม่ได้เกิดขึ้นจริง

## สิ่งที่ควรรู้ก่อนใช้งาน

Discord สามารถเปลี่ยนระบบตรวจจับเกมหรือการแสดง Activity ได้ในอนาคต หากโปรแกรมไม่แสดงผล ควรตรวจสอบว่าเปิด Discord Desktop อยู่ เปิดการแสดง Activity Status แล้ว และใช้โปรแกรมเวอร์ชันล่าสุด

โปรแกรมนี้ไม่ควรขอรหัสผ่าน Discord หรือ Token บัญชี หากพบไฟล์จากแหล่งอื่นที่ร้องขอข้อมูลดังกล่าว ไม่ควรใช้งาน

## สรุป

PUNN Activity Studio เป็นโปรเจกต์ขนาดเล็กที่เน้นความสนุกและการทดลองระบบ Discord Activity จุดสำคัญคือมันเปลี่ยนเฉพาะสิ่งที่แสดงบนสถานะ ไม่ได้ทำให้บัญชีเป็นเจ้าของเกมหรือกำลังเล่นเกมนั้นจริง ๆ
