# MemoKard เรียนให้จำ ไม่ใช่แค่อ่านผ่าน

[MemoKard](https://memokard.vercel.app/) คือเว็บแอปแฟลชการ์ดภาษาไทยที่ผมทำขึ้นมาเพื่อช่วยทบทวนสิ่งที่เรียนอย่างเป็นระบบ แทนที่จะเปิดโน้ตเดิมอ่านซ้ำไปเรื่อย ๆ ตัวแอปจะให้เราพยายามนึกคำตอบก่อนเปิดดูเฉลย ซึ่งเป็นแนวคิดของ **Active Recall**

หลังตอบเสร็จ ผู้ใช้สามารถประเมินได้ว่าการ์ดนั้นยากหรือง่ายเพียงใด ระบบจะนำผลไปคำนวณวันที่ควรนำการ์ดกลับมาทบทวนอีกครั้ง

<!-- รูปที่ต้องเพิ่ม: ภาพปกหรือ Dashboard ของ MemoKard -->

## FSRS คืออะไร?

ชื่อที่ถูกต้องคือ **FSRS — Free Spaced Repetition Scheduler** เป็นระบบจัดตารางทบทวนแบบเว้นระยะ โดยพยายามประเมินว่าเรายังจำการ์ดแต่ละใบได้มากน้อยแค่ไหน แล้วเลือกเวลาที่เหมาะสมในการนำกลับมาถามใหม่

การ์ดที่ตอบไม่ได้จะกลับมาเร็ว ส่วนการ์ดที่จำได้ดีจะถูกเว้นระยะออกไป ทำให้ไม่ต้องเสียเวลาทบทวนทุกใบเท่ากัน และสามารถโฟกัสกับเนื้อหาที่ยังไม่แม่นได้มากกว่า

## จุดเด่นของ MemoKard

- ใช้ Active Recall ร่วมกับ FSRS
- สร้าง Deck และการ์ดของตัวเองได้
- ทำงานแบบ Offline-first
- เก็บข้อมูลหลักบนอุปกรณ์ด้วย IndexedDB
- ติดตั้งเป็น PWA บนคอมพิวเตอร์และโทรศัพท์ได้
- มี Dark mode, สถิติ และ Achievement
- รองรับ Community Decks
- เลือกซิงก์บัญชีและข้อมูลผ่าน Supabase ได้

## Offline-first ใช้งานอย่างไร?

MemoKard ออกแบบให้ข้อมูลในเครื่องเป็นศูนย์กลาง ผู้ใช้สามารถทดลองสร้าง Deck และทบทวนการ์ดได้แม้ไม่ได้ตั้งค่า Backend หรือขาดการเชื่อมต่ออินเทอร์เน็ต

เมื่อเปิดใช้ระบบบัญชีและ Supabase แอปสามารถจัดคิวการเปลี่ยนแปลงที่เกิดขึ้นระหว่าง Offline แล้วซิงก์ภายหลังเมื่อกลับมาออนไลน์ แนวทางนี้ช่วยให้การกดทบทวนแต่ละครั้งตอบสนองเร็วและไม่จำเป็นต้องรอเซิร์ฟเวอร์ตลอดเวลา

> หากใช้งานแบบ Local อย่างเดียว ควร Export Deck สำรองเป็นระยะ เพราะการล้างข้อมูลเว็บไซต์ของเบราว์เซอร์จะลบข้อมูลที่เก็บอยู่ในอุปกรณ์นั้น

## ใช้ MemoKard เรียนอะไรได้บ้าง?

รูปแบบแฟลชการ์ดเหมาะกับเนื้อหาที่ต้องเรียกคืนจากความจำ เช่น

- คำศัพท์และประโยคภาษาต่างประเทศ
- สูตรคณิตศาสตร์หรือวิทยาศาสตร์
- คำสั่งโปรแกรมและแนวคิดทางเทคนิค
- ชื่อบุคคล เหตุการณ์ และวันที่สำคัญ
- คำถามเตรียมสอบหรือสัมภาษณ์

หัวใจสำคัญคือเขียนคำถามให้เฉพาะเจาะจง หนึ่งการ์ดควรถามหนึ่งเรื่อง และพยายามตอบด้วยตัวเองก่อนเปิดดูด้านหลัง

## PWA และการติดตั้ง

MemoKard เป็น PWA จึงสามารถเพิ่มไว้บนหน้าจอหลักหรือ Start Menu ได้ หลังติดตั้งจะเปิดในหน้าต่างแยกเหมือนแอปทั่วไป แต่ยังได้รับการอัปเดตผ่านเว็บ

ทดลองใช้งานได้ที่ [memokard.vercel.app](https://memokard.vercel.app/) และดู Source code ได้ที่ [GitHub: DDME36/MemoKard](https://github.com/DDME36/MemoKard)

## สรุป

MemoKard เป็นมากกว่าเว็บพลิกบัตรคำ เพราะมีทั้งระบบจัดตารางทบทวน FSRS การทำงานแบบ Offline-first และตัวเลือกซิงก์ข้อมูล เหมาะทั้งสำหรับทดลองสร้างชุดการ์ดสั้น ๆ และใช้ทบทวนเนื้อหาในระยะยาว โดยยังคงให้ผู้ใช้เป็นเจ้าของข้อมูลของตัวเอง
